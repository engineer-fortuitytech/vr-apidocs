Breeze API

Integrate Breeze Commercial Insurance Products into your apps.

The Breeze API lets you search for business classifications, request appetite checks for businesses you'd like to quote, and power builds multiple product quotes on demand. Use it from mobile, web, or backend services with a simple REST interface.

REST · JSON Auth: API key (header) Environment: Production

How to use the API

  1. 1
    Get an API key

    Obtain your API key from the Velocity Risk Partner team and store it securely. You’ll send it as a header on every request: 

    x-api-key: <YOUR_API_KEY>
  2. 2
    Call endpoints from your app

    Use the REST endpoints to find business classifications, request appetite checks for businesses you'd like to quote, and create multiple quote types. The API speaks standard JSON over HTTPS.

    Handle responses gracefully

    Responses return machine-friendly JSON plus HTTP status codes. You can plug results directly into UI components like "Approved quote" or "Occupancy Accepted".

Key features

  • Structured appetite checks

    Check Appetite for CPP and BOP products with a single API call, using structured signals like business type, size, and risk factors.

  • Simplify Quoting

    Receive indicative quotes for BOP and CPP products and create and submit a quote to underwriting with a single API call

  • Operational monitoring

    A built-in health check lets you quickly verify API availability from your dashboards or uptime monitors.

Typical use cases

  • Occupancy Availability

    Quickly check if a business is within appetite for CPP or BOP products based on natural language inputs.

  • Appetite Verification

    Verify if a business and/or property location is within appetite for CPP and BOP products with a single API call.

  • Chatbots / assistants

    Let conversational agents call the API to help users find relevant insurance products, check appetite, and get quotes in real time.
